# Operating Systems Core Notes

A focused single-page revision guide for core Operating Systems concepts, from processes and CPU scheduling to memory, synchronization, deadlocks, file systems and I/O.

![Operating Systems Core Notes preview](screenshot.png)

## Features

- Structured notes grouped by major Operating Systems topics
- Expandable topic sections and interview-focused questions
- Dark and light theme support with local persistence
- Fixed header with local branding and independent page scrolling
- Icon-only social and support footer with a floating go-to-top control

## Tech stack

React, Vite, styled-components and React Icons.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npm run deploy
```

Live site: [Operating Systems Core Notes](https://a2rp.github.io/operating-systems-core-notes/)
